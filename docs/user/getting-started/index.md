Install DesignCraft first, then start a document.

1. [Install DesignCraft](install.md) on Windows 11, macOS or Linux.
2. On the start screen, choose **New file** or **Open**. In the desktop app, **Join shared document…** lets you enter a collaborator’s invitation.
3. Choose **Help > Sample Document** to see a finished layout, or follow [Create a new document](../guides/create-a-document.md) to begin your own.

DesignCraft also runs in a web browser. See [Which systems does DesignCraft run on?](../faq/supported-systems.md).
